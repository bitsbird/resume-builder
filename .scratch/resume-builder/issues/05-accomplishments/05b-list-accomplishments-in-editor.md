# #05b — List accomplishments under WE in editor

## Parent

[#05 Accomplishments (selection + linking)](issue.md)

## What to build

Each WE card in the editor shows the accomplishments already linked to that WE in this resume. When a WE is added to the editor, its previously-linked accomplishments are pre-selected and displayed. The list is read-only in this subtask (selection and reordering are handled in later subtasks).

## Acceptance criteria

- [ ] Each WE card in the editor shows a list of its linked accomplishments
- [ ] When a WE is added to the resume, any accomplishments already linked to it in this resume are pre-loaded and displayed
- [ ] The list renders in position order
